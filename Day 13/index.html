Units in CSS

---unit -- a measurement of size in CSS, such as pixels, ems, rems, etc.

  • pixel -- fix unit
  • rem -- for font size, relative to root element / html document
  • em -- for font size, relative to parent element
  • vh -- for height, relative to viewport height
  • vw -- for width, relative to viewport width
  • % -- for size, relative to parent element
